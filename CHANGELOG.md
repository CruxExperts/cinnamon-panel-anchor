# Changelog

## 0.2.2 - 2026-05-22

- Added release asset tooling for a checksum-verified installer, versioned app bundle, and SHA256SUMS.
- Added durable release install behavior with a persistent backend source path and stable applet launcher.
- Reworked public docs around monitor-index drift, applet-first use, and release installer flow.
- Replaced and documented generated public visuals with explicit asset provenance.
- Preserved the invariant that the project never changes display primary.

## 0.2.1 - 2026-05-22

- Reworked the project direction around a native Cinnamon applet with UUID `cinnamon-panel-anchor@cruxexperts.com`.
- Added applet package assets, settings schema, stylesheet, and installer/export commands.
- Standardized applet-facing JSON backend commands for status, capture, restore, and diagnostics.
- Added GitHub-ready documentation, Cinnamon Spices submission notes, generated project-owned mockups, and diagrams.
- Removed the pre-release background watcher surface from the applet, CLI, settings, and docs.
- Replaced generic theme status icons with a custom panel-anchor logo and packaged state icon family.
- Preserved the invariant that the project never changes display primary.
