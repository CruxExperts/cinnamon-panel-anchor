# Project-Owned Visual Assets

These assets are generated for this repository and do not copy external Crux site artwork.

## Style Notes

- Native Cinnamon inspired: panel icon, popup menu, notification bubble, and monitor mapping.
- Professional operational palette: deep blue, soft neutral, muted teal, and restrained status colors.
- Mockups in `docs/assets/readme/` are development previews until replaced by real Cinnamon screenshots.

## Reproducibility Notes

- SVG files are hand-authored project assets.
- PNG files are generated from simple project-owned layouts and are placeholders for README polish.
- Before Cinnamon Spices submission, replace development mockups with real screenshots from Linux Mint Cinnamon/X11 and add `screenshot.png` to the generated Spice export.
