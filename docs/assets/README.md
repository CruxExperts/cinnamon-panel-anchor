# Project-Owned Visual Assets

These assets are generated or authored for this repository and do not copy external Crux site artwork.

## Manifest

Public image provenance is tracked in [manifest.json](manifest.json). The manifest records each image path, dimensions, generated status, tool/model note, prompt summary, and whether it is a real Cinnamon screenshot.

No generated image in this repository is a real Cinnamon screenshot.

## Current Images

- `docs/assets/readme/hero.png` is a generated README hero visual.
- `docs/assets/social/social-preview.png` is a generated social preview background. Exact social-card title and copy are maintained outside model-rendered image text.
- `docs/assets/readme/dashboard-mockup.png` is a generated applet-popup mockup.
- `docs/assets/readme/notification-mockup.png` is a generated notification mockup.
- `docs/assets/brand/panel-anchor-logo.svg` is the horizontal documentation logo.
- `docs/assets/brand/anchor-icon.svg` is the square product icon used to derive PNG brand assets.
- `docs/assets/diagrams/applet-backend-flow.svg` documents the applet-to-backend command flow and is linked from the architecture guide.

## Style Notes

- Native Cinnamon inspired: panel-anchor logo, popup menu, notification bubble, and monitor mapping.
- Professional operational palette: deep blue, soft neutral, muted teal, and restrained status colors.
- Generated README mockups are development previews until replaced by real Cinnamon screenshots.

## Reproducibility Notes

- SVG files are hand-authored project assets.
- PNG brand icons are generated from the same project-owned panel-anchor shape.
- README and social PNG files are generated project visuals and explicitly labeled in public docs.
- Before Cinnamon Spices submission, replace development mockups with real screenshots from Linux Mint Cinnamon/X11 and add `screenshot.png` to the generated Spice export.
