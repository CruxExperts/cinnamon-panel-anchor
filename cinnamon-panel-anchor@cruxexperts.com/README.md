# Cinnamon Panel Anchor

Cinnamon Panel Anchor v0.2.2 is a native Cinnamon applet backed by a Python utility. It keeps Linux Mint Cinnamon/X11 panels tied to the monitor connector and edge you saved.

This checked-in layout mirrors the Cinnamon Spices export shape. It restores Cinnamon panel placement when monitor indexes drift without changing the primary monitor. Generated documentation visuals are not real Cinnamon screenshots. Add `screenshot.png` only after capturing the running applet in Cinnamon.

The applet uses a custom panel-anchor icon family in `files/cinnamon-panel-anchor@cruxexperts.com/icons/` rather than generic desktop status icons.

Startup uses Cinnamon's enabled applet list. **Quit for Session** is temporary; **Disable Applet** removes the persistent Cinnamon enabled-applet entry.
